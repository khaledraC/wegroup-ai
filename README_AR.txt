WE GROUP AI — نسخة قابلة للربط

المتطلبات: Node.js 18 أو أحدث + مفتاح OpenAI API صالح مع تفعيل الفوترة.

1) افتح الطرفية داخل المجلد.
2) ضع OPENAI_API_KEY في متغيرات البيئة لدى الاستضافة. لا تضعه في HTML ولا ترسله لأحد.
3) شغل: npm start
4) افتح http://localhost:3000
5) اختبر نافذة المساعد.

مهم: Netlify Drop الثابت لا يشغل server.js؛ تحتاج استضافة Node.js مثل Render أو Railway أو خدمة مماثلة.
المساعد هنا يعمل داخل الموقع فقط، ولا يرسل أو يستقبل رسائل واتساب تلقائيًا. ربط واتساب الرسمي خطوة لاحقة تتطلب WhatsApp Business Platform وwebhook آمن.
قبل الاستخدام العام: أضف سياسة خصوصية وموافقة، تحكمًا أفضل في المعدل، وسجل مراجعة ومراقبة تكاليف وحماية بيانات العملاء.
